# AI/ML-Based Predictive Maintenance and Vehicle Health Monitoring System
## Project Overview
This project develops an AI/ML-based predictive maintenance system for electric vehicles. The system uses vehicle telemetry data to predict the probability of failure and generate a vehicle health score and maintenance alert.
## Objectives
* Analyze EV sensor and operational data.
* Predict potential vehicle/component failures.
* Compare different machine learning and deep learning models.
* Generate a vehicle health score and maintenance status.
* Identify important vehicle parameters using feature importance.
## Dataset
The project uses the **EVIoT Predictive Maintenance Dataset** containing 175,393 records and 30 features.
The selected input parameters include battery, motor, braking, and driving-related measurements. The target variable is `Failure_Probability`.
## Models Used
* Logistic Regression
* Random Forest
* XGBoost
* LSTM
## Project Workflow
Vehicle Telemetry → Data Preprocessing → ML/DL Models → Failure Probability → Vehicle Health Score → Maintenance Alert

Python, Pandas, NumPy, Scikit-learn, XGBoost, TensorFlow/Keras, Matplotlib, and Seaborn.
## Conclusion
The project demonstrates how machine learning and deep learning can be applied to vehicle telemetry for predictive maintenance and vehicle health monitoring.
